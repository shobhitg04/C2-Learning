# Review spec

Review a spec file for missing requirements, ambiguous words, contradictions with other files in `spec/`, and untestable statements.

## Steps

1. Read the spec file under review.
2. Read the other files in `spec/`.
3. Find missing requirements.
4. Flag ambiguous words.
5. Flag contradictions with other files in `spec/`.
6. Flag untestable statements.
7. List anything that still needs a decision as an open question.

## Output format

### Findings

1. **Kind** — file and location. What is missing, ambiguous, contradictory, or untestable.

### Open questions

1. Question that the spec does not answer.
